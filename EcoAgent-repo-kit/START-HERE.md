# Two-person kickoff

1. Download/unzip this kit and read README.md. It is documentation only.
2. Review the proposed MVP together. If this is different from your intended EcoAgent, revise product and contract before giving implementation prompts to AI.
3. Copy the kit contents into the SBUHack repository root on Sean_branch. The old README is one line, but still inspect git diff before committing.
4. Commit the shared docs/contracts and merge their reviewed PR into main. Both working branches then merge origin/main.
5. Sean pastes prompts/SEAN.md into his AI coding assistant. Muffin pastes prompts/MUFFIN.md into theirs. Give the assistant access to the local clone or repository; a prompt alone does not grant GitHub access.
6. Connect one real frontend-to-backend demo task before expanding the app. Keep main runnable after each milestone.
7. Follow docs/04-acceptance-and-demo.md and docs/05-submission.md for final checks and presentation.

No repository files were pushed or changed remotely when this kit was prepared. No product code has been built. The API and sample arithmetic have been checked as design artifacts; application tests must be run during implementation.
