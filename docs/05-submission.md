- Accurate one-paragraph problem and solution explanation.
- Repository link and reproducible setup instructions.
- Demo URL if available; local/offline fallback and a short recording.
- Screenshots that preserve simulated/estimated labels.
- Architecture diagram or concise description; stack and genuine contributions.
- Honest limitations and next steps; identification of third-party tools, models and AI assistance where applicable or requested.
- Both teammates added to the submission; select tracks only if eligible.

Draft only statements supported by the completed implementation. Do not advertise optional live integration, telemetry, calibrated carbon measurements, or quality guarantees if not implemented and verified.
